## About

DevOps Engineer focused on building and operating cloud-native infrastructure. I work across the full delivery lifecycle: container orchestration, CI/CD pipelines, monitoring and alerting, and incident response. Outside of day-to-day operations, I build open-source tools that make life easier for platform and on-call teams.

- **Focus areas:** Kubernetes, platform engineering, observability, site reliability
- **Currently building:** self-hosted tooling for on-call management and cluster security
- **Open to:** collaboration on DevOps, SRE and open-source infrastructure projects
